🚀 QUICK START GUIDE:

┌─────────────────────────────────────────────────────────────────────┐
│  METHOD 1: Full Stack (Backend + Frontend)                          │
└─────────────────────────────────────────────────────────────────────┘

1. Install Dependencies:
   
   cd client
   npm install
   cd server
   pip install -r requirements.txt

2. Start Backend (Terminal 1):
   
   cd client
   start_server.bat
   
   OR manually:
   cd client/server
   python dashboard_server.py

3. Start Frontend (Terminal 2):
   
   cd client
   npm run dev

4. Open Browser:
   
   http://localhost:3000

┌─────────────────────────────────────────────────────────────────────┐
│  METHOD 2: Mock Mode (Frontend Only - No Backend Required)          │
└─────────────────────────────────────────────────────────────────────┘

1. Install Dependencies:
   
   cd client
   npm install

2. Enable Mock Mode:
   
   Create .env file:
   VITE_USE_MOCK=true

3. Update Dashboard.jsx:
   
   Uncomment this line:
   import { MockWebSocketService as WebSocketService } 
     from '../services/mockData';

4. Start Frontend:
   
   npm run dev

5. Open Browser:
   
   http://localhost:3000

┌─────────────────────────────────────────────────────────────────────┐
│  METHOD 3: One-Click Setup (Windows)                                │
└─────────────────────────────────────────────────────────────────────┘

   cd client
   setup.bat

Fix:  Change port in vite.config.js

Issue: Port 8000 already in use
Fix:  Change port in dashboard_server.py

Issue: CORS errors
Fix:  Already configured, check firewall

Issue: WebSocket connection failed
Fix:  1. Ensure backend is running
      2. Check VITE_WS_URL in .env
      3. Use mock mode as fallback

Issue: npm install errors
Fix:  npm cache clean --force
      rm -rf node_modules package-lock.json
      npm install
